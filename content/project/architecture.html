1. Foundations

System Architecture & Interface Contract

3-stage offline pipeline, data structures, and local REST API interface.

1. Decoupled 3-Stage Pipeline

DepthWizard separates computational workloads into three discrete execution stages:

  1. Stage 1 (Elevation Extraction): Ingests optical images, performs GSD normalization, and runs Depth Anything V2 inference to output a relative depth map.
  2. Stage 2 (Scale Calibration): Fits per-land-cover affine parameters against SRTM 30m reference DEMs, generating a 16-bit metric DSM.
  3. Stage 3 (Visualization Layer): Packages heightmap, confidence texture, and RGB imagery into a Three.js textured PlaneGeometry mesh for real-time navigation.

2. Local REST API Contract (FastAPI)

The backend serves inference results locally over localhost:8000 via three fixed endpoints:

POST /upload • Multipart form (file)
Returns: { "image_id": "uuid", "input_type": "georeferenced" | "non_georeferenced", "metadata": {...} }
POST /process/{image_id}?with_uncertainty=true • Single blocking call
Returns: { "heightmap_png_b64": "...", "confidence_png_b64": "...", "texture_png_b64": "...", "height_min": 0.12, "height_max": 24.87 }
GET /result/{image_id} • Retrieve packaged result or processing status.
