1. Sentinel-1 Synthetic Aperture Radar (SAR)

The Copernicus Sentinel-1 constellation comprises two polar-orbiting satellites equipped with C-band radar instruments operating at a central frequency of 5.405 GHz.

Key Ingestion Specifications

Acquisition Mode: Interferometric Wide (IW)
Product Type: Ground Range Detected (GRD)
Polarization: Dual (VV + VH)
Pixel Spacing: 10m × 10m
Radiometric Depth: 16-bit unsigned integer
Swath Width: 250 km

Geographic Coverage: Primary focus areas include Indian Exclusive Economic Zone (EEZ) coastal transit lanes, the Arabian Sea tanker highway, the Gulf of Mannar, and the Bay of Bengal international shipping corridors.

2. Automatic Identification System (AIS) Telemetry

The Automatic Identification System is an automated tracking system that uses VHF transceivers on ships. Under IMO SOLAS Regulation V/19, all commercial ships of 300 gross tonnage and upwards engaged on international voyages must broadcast AIS messages.

TRACEOIL ingests raw AIS records and builds continuous kinematic trajectory models:

  • Message Types 1, 2, 3: Position Reports (MMSI, navigational status, rate of turn, SOG, longitude, latitude, COG, true heading, timestamp).
  • Message Type 5: Ship static and voyage-related data (IMO number, call sign, vessel name, ship type, dimensions, draft, destination).

3. M4D ITI Oil Spill Benchmark Dataset

To evaluate segmentation algorithms against established scientific literature, TRACEOIL references the publicly available Oil Spill Detection Dataset created by the Information Technologies Institute (CERTH-ITI).

The dataset contains Sentinel-1 SAR image patches with manually verified ground-truth semantic annotations across 5 distinct classes:

Class ID Class Name Description Pixel Annotation Color
0 Sea Surface Undisturbed open water background clutter Black (0, 0, 0)
1 Oil Spill Confirmed crude oil / bilge discharge slicks Cyan (0, 255, 255)
2 Lookalike Biogenic slicks, low wind grease, internal waves Amber (255, 170, 0)
3 Ship Target Metallic vessel point reflections Red (255, 0, 0)
4 Land / Coast Terrestrial features, islands, shorelines Dark Gray (128, 128, 128)

5. Dataset Limitations

Known Data Constraints
  • Revisit Latency: Sentinel-1 single satellite constellation revisit time over Indian waters ranges between 6 to 12 days, necessitating temporal interpolation between successive passes.
  • Cloud Cover in Optical Data: Sentinel-2 optical verification is frequently obstructed during monsoon seasons, making SAR the solely reliable continuous detection modality.
  • Terrestrial AIS Range Limits: Terrestrial coastal AIS receiver stations lose vessel coverage beyond 25–40 nautical miles, requiring satellite-AIS aggregators for deep-sea passages.
